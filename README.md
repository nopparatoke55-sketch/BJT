AC Phasor & Impedance Calculator (โปรแกรมคำนวณเฟสเซอร์และอิมพีแดนซ์กระแสสลับ)
โปรแกรมคำนวณวงจร RLC ที่รองรับการประมวลผลตัวเลขเชิงซ้อน (Complex numbers) เพื่อหาค่าอิมพีแดนซ์รวม กระแส และมุมเฟส วัตถุประสงค์เพื่อใช้ตรวจสอบความถูกต้องของทิศทางเฟสและผลลัพธ์ในการวิเคราะห์วงจรไฟฟ้ากระแสสลับ

Truss Analysis Solver (โปรแกรมวิเคราะห์แรงในโครงถัก 2 มิติ)
โปรแกรมที่ใช้หลักการพีชคณิตเชิงเส้น (Linear Algebra) และเมทริกซ์ในการแก้สมการหาค่าแรงดึงและแรงอัดในชิ้นส่วนโครงถัก (Method of Joints) วัตถุประสงค์เพื่อลดความซับซ้อนในการคำนวณมือและช่วยทบทวนเนื้อหาในรายวิชา Statics

Damped Harmonic Motion Visualizer (โปรแกรมจำลองการสั่นแบบหน่วง)
สคริปต์ Python ที่ใช้ไลบรารีคณิตศาสตร์แก้สมการเชิงอนุพันธ์ (Differential Equations) ของระบบมวล-สปริง-ตัวหน่วง แล้วพล็อตเป็นกราฟ วัตถุประสงค์เพื่อให้เห็นภาพพฤติกรรมการตอบสนองของระบบทางฟิสิกส์และกลศาสตร์เมื่อมีการหน่วง

Digital Logic IC Tester (เครื่องทดสอบไอซีลอจิกเกตพื้นฐาน)
ระบบฮาร์ดแวร์ที่ใช้ไมโครคอนโทรลเลอร์ (เขียนด้วยภาษา C) จ่ายสัญญาณอินพุตเข้าทดสอบชิปตระกูล 74xx แล้วเปรียบเทียบผลลัพธ์กับ Truth Table ในหน่วยความจำ วัตถุประสงค์เพื่อประยุกต์ใช้วงจรดิจิทัลในการสร้างเครื่องมือตรวจสอบอุปกรณ์ว่าเสียหรือไม่
